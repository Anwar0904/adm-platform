## Archive policy

Keep evidence and active implementation docs discoverable in-repository. Do not move historical/product docs to an archive until the documentation owner confirms canonical copies, links, and retention. No docs were archived in this pass. Refresh the inventory when routes, dependencies, runtime config, or release evidence changes.
